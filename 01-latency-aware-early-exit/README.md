出口置信度和预测来自在 MNIST 上训练的两出口 CNN（`src/train.py`，需要 PyTorch；`figs/exit_outputs_seed*.npz` 与 `figs/compute_timing.csv` 已提交，实验不必重新训练）。链路不经过网卡：带宽、传播时延和抖动在 `src/netsim.py` 里换成时延，不发送数据包。

三种网络、三档预算。参数都在**该网络、该预算的验证集**上按按时正确率选取，再在测试集上计分。时延感知用 EWMA 跟踪最近链路时延（提前退出时用一次探测更新估计）。固定阈值在一次测试中不变。

- **稳定**：40 Mbit/s、传播时延 8 ms、抖动为 0。继续推理约 10 ms。
- **中等波动**：常态 50 Mbit/s、8 ms、抖动 1 ms，偶发较短的轻度拥塞（约 12 Mbit/s、16 ms、抖动 3 ms），外加小幅带宽起伏。
- **强波动**：常态约 80 Mbit/s、6 ms，带宽起伏更大；拥塞突发约 3.5 Mbit/s、35 ms、抖动 6 ms。突发时继续推理约 50 ms。
- **预算**：紧 12 ms、中 20 ms、松 80 ms。

```bash
python3 -m src.train        # 可选；需要 torch。已提交出口输出和阶段耗时，可跳过
python3 -m src.experiment   # numpy / matplotlib
python3 -m pytest -q
```

稳定网络的三档预算，以及三种网络的宽松预算，截止命中率都是 1。时延感知的按时正确率不高于固定阈值，差距在 0.003 以内（稳定、紧预算低 0.0026）。链路不变或预算盖过突发时，在线调整没有优势。

中等波动、紧预算：时延感知按时正确率 0.9673，比固定阈值高 0.0135；截止命中率 0.9880，高 0.0162。中等波动、中预算的差距缩小到按时正确率 +0.007、命中率 +0.010。强波动、紧预算：按时正确率 0.9522 对 0.9239（+0.028），命中率 0.9854 对 0.9527（+0.033）。强波动、中预算同样约为 +0.030 和 +0.032。这几格里时延感知的原始准确率略低于固定阈值（约 0.002–0.003），多出来的按时正确率来自更少的超时。三个种子的方向与均值一致，见 `regime_budget_per_seed.csv`。
